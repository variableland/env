`@vlandoss/env` is open source. We build it in the open, and we'd love your help.

## Contributing

The code lives at [github.com/variableland/env](https://github.com/variableland/env). Whether you're filing a bug, suggesting a feature, polishing the docs, or sending a PR, here's where to start:

- **Found a bug?** [Open an issue](https://github.com/variableland/env/issues/new) with a minimal reproduction — that's the fastest path to a fix.
- **Have an idea?** Start a [discussion](https://github.com/variableland/env/discussions) so we can shape it together before code is written.
- **Want to send a PR?** Check the contributing guide in the repo, branch from `main`, and feel free to ping us in the PR if anything is unclear.
- **Improving these docs?** Every page on this site has an "Edit on GitHub" link in the actions row — open a PR with the change you'd like to see. Doc fixes are some of the most appreciated contributions.

## About Variable Land

`@vlandoss/env` is one of the open source projects we maintain at [Variable Land](https://variable.land/) — a small studio that builds tools we wanted to use ourselves.

Follow along:

- **[GitHub](https://github.com/variableland)** — every project we ship, in one place.
- **[variable.land](https://variable.land/)** — what we're working on lately.

If `@vlandoss/env` is useful to you, starring [the repo](https://github.com/variableland/env) is the cheapest way to tell us to keep going.
